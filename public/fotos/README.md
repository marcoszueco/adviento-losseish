# Fotos del calendario

Coloca aquí las 25 fotos con estos nombres exactos:

```
01.jpg  02.jpg  03.jpg  ...  24.jpg  25.jpg
```

- La foto `01.jpg` se ve al abrir el día 1, la `02.jpg` el día 2, etc.
- La foto `25.jpg` es la **foto especial** del día 25.
- Si usas otra extensión (`.png`, `.webp`, `.jpeg`), cámbiala en `src/config.ts` → `photoExtension`.
- Mientras no haya fotos, se muestra una tarjeta decorativa de respaldo con el número del día, así que puedes ver el calendario funcionando sin problema.
- Recomendación: imágenes horizontales de al menos 1200 px (se recortan a 16:10 en la ventana del día) y optimizadas en JPG/WebP para que carguen rápido.
