# Fotos del calendario

Coloca aquí las 24 fotos con estos nombres exactos:

```
01.jpg  02.jpg  03.jpg  ...  24.jpg
```

- La foto `01.jpg` se verá al abrir el día 1, la `02.jpg` el día 2, etc.
- Si usas otra extensión (`.png`, `.webp`, `.jpeg`), cámbiala en `src/config.ts` → `photoExtension`.
- Mientras no haya fotos, el calendario muestra una tarjeta decorativa de respaldo, así que puedes verlo funcionar sin problema.
- Recomendación: imágenes cuadradas o horizontales de al menos 800 px y optimizadas (WebP/JPG) para que carguen rápido.

Si renombras las fotos, recuerda actualizar también las frases en `src/data/days.ts`.
